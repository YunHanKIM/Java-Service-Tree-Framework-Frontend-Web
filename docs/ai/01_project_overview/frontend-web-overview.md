# Frontend-Web — 프로젝트 개요

서비스명: **지원노트** — AI 채용공고 분석 · 이력서 비교 · 지원 관리 웹 서비스.
Next.js(App Router) + TypeScript + shadcn/ui 풀스택 앱 — 자체 API 라우트가 실제 OpenAI/Anthropic
API·URL fetch·PDF 파싱을 수행한다 (`02_tech_stack` 참조).

> 이 저장소는 원래 Java-Service-Tree-Framework MSA의 프론트엔드 모듈 스캐폴딩으로 시작했으나,
> 2026-09-23 포트폴리오 프로젝트("지원노트")로 범위를 확정했다. 초기 구현은 빌드 도구 없는
> vanilla JS였으나, 같은 날 Next.js 스택으로 전면 재구축했다(사용자 피드백 — 실제로 동작하는
> AI 연동·링크 가져오기·풍부한 UI 필요). Backend-Core(A-RMS) 연동은 이 기능 범위에 포함되지 않는다 —
> 상세는 `09_api_contract` 참조.

## 목적

취업 준비 과정에서 반복되는 "채용공고 확인 → 내 역량과 비교 → 지원 여부 결정 → 지원 현황 관리 →
면접 준비"의 흐름을 한 화면에서 처리하는 도구. 포트폴리오 목적상 다음 역량을 보여주는 데 집중한다.

- 복잡한 상태 관리 (칸반 드래그 앤 드롭, 낙관적 업데이트)
- 비동기 UI (AI 분석 로딩·스트리밍처럼 보이는 단계적 렌더링, 실패 복구)
- 폼 처리와 클라이언트 사이드 데이터 검증
- 반응형·접근성을 갖춘 실무 수준 UI 완성도

## 핵심 사용자 흐름

1. 채용공고를 링크·본문 붙여넣기·PDF 업로드 중 한 가지 방법으로 등록한다.
2. AI(사용자가 등록한 OpenAI/Anthropic API 키로 실제 호출)가 공고에서 회사·직무·자격요건을 자동 추출한다.
3. 사용자가 추출 결과를 확인·수정하고 저장한다.
4. AI가 내 이력서와 공고를 비교해 일치하는 경험·보완할 경험·분석 근거를 제시한다.
5. 지원 상태를 칸반 보드(관심 → 지원예정 → 지원완료 → 면접 → 결과)로 관리한다.
6. 저장된 공고를 기준으로 예상 면접 질문을 생성하고 답변을 작성한다.

## 범위 (이 구현의 경계)

- **포함**: 자체 서버 인증(bcrypt+세션 쿠키), 공고 등록/검색/필터, 실제 AI 분석(적합도·부족기술·근거,
  사용자 API 키 필요), 실제 URL 가져오기·PDF 텍스트 추출, 칸반 지원 관리, 면접 질문 생성·답변 작성,
  대시보드 통계, 반응형·로딩/빈화면/오류 상태.
- **제외** (`12_known_issues` 참조): 실제 DB(Postgres/Supabase 등 — 도메인 데이터는 localStorage),
  기기 간 데이터 동기화, 브라우저 확장 프로그램, 자동화 테스트 스위트(수동/Playwright 스모크만 수행).

## MSA 내 위치 (레거시 — 이 기능 범위에서는 미사용)

- 상위: Backend-Core (REST/컨트롤러 엔드포인트 제공, `/arms/...` 관례)
- 인증/게이트웨이: Middle-Proxy 경유 가능성 있음 (Backend-Core 문서 참조)
- 향후 이 저장소가 원래 목적(Java-Service-Tree-Framework 프론트엔드)으로 다시 쓰일 경우를 대비해
  섹션은 보존하되, 현재 구현과는 무관함을 명시한다.
