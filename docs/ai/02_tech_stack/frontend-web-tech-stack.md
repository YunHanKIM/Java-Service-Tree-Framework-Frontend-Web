# Frontend-Web — 기술 스택

| 구분 | 값 |
|------|-----|
| 마크업 | 시맨틱 HTML |
| 스타일링 | Bootstrap (그리드/컴포넌트/유틸리티) |
| 스크립팅 | vanilla JavaScript + jQuery |
| 렌더링 방식 | 서버렌더링 / 멀티페이지 |
| 백엔드 연동 | AJAX(`$.ajax`/`fetch`) → Backend-Core 엔드포인트 |
| 빌드 도구 | 없음 (정적 파일, CDN 로드) |
| Bootstrap 버전 | 5.3.3 (CDN) |
| jQuery 버전 | 3.7.1 (CDN) |

> 버전은 스캐폴딩 시점 임의 선택 — 프로젝트 요구사항에 맞지 않으면 교체 가능.
