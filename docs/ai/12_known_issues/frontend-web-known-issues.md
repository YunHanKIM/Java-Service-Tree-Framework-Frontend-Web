# Frontend-Web — 함정·안티패턴

## 지원노트 구현의 의도된 한계 (포트폴리오 범위)

- **AI 분석은 실제 LLM 호출이 아니다.** `assets/js/common/mock-ai.js`는 규칙 기반 시뮬레이션이다.
  브라우저에서 직접 OpenAI 등 API 키를 사용하면 키가 클라이언트 번들에 노출되므로 의도적으로 배제했다.
  실제 연동은 별도 백엔드 프록시가 필요 — `09_api_contract` 참조.
- **URL/PDF 입력은 실제로 내용을 가져오지 않는다.** 링크 입력·PDF 업로드는 UI/흐름만 구현하고,
  실제 크롤링·텍스트 추출 없이 목데이터를 반환한다(추천 PDF 자료도 실제 크롤링 서비스 확장은
  권장하지 않음 — 채용 사이트 정책·봇 차단 이슈).
- **localStorage는 브라우저·기기 단위 저장이다.** 서버 동기화가 없어 다른 브라우저/기기에서는
  데이터가 보이지 않는다. 데모/포트폴리오 시연 시 유의.
- **네비게이션 마크업은 페이지마다 복제된다.** 빌드 도구·템플릿 엔진이 없어 `pages/*.html` 각각에
  사이드바/상단바 마크업을 직접 포함한다 — 레이아웃 변경 시 전체 페이지를 동기화해야 한다
  (`assets/js/common/nav.js`가 활성 메뉴 표시만 공통 처리).
- **로그인은 실제 인증이 아니다.** 서버 검증 없는 목 세션(`assets/js/common/auth.js`)이다.
