# Frontend-Web — AI 하네스

이 폴더는 AI 워커(frontend-expert 등)가 Frontend-Web 작업 전 읽는 정본 문서 모음이다.
Java-Service-Tree-Framework MSA의 프론트엔드 모듈이며, Backend-Core의 API를 소비한다.

| 폴더 | 용도 | 상태 |
|------|------|------|
| `01_project_overview/` | 프로젝트 목적·MSA 내 위치 | 초안 |
| `02_tech_stack/` | 언어·프레임워크·버전 | 초안 |
| `03_directory_structure/` | 디렉터리 배치 규약 | 미정 |
| `04_coding_standards/` | 코딩 규칙 | 초안 |
| `05_prompt_templates/` | 반복 작업용 프롬프트 템플릿 | 미정 |
| `06_domain_playbooks/` | 도메인별 작업 규칙 | 미정 |
| `06_page_playbooks/` | 화면(페이지)별 작업 규칙 | 미정 |
| `07_review_checklist/` | 제출 전 자가검토 체크리스트 | 초안 |
| `08_domain_glossary/` | 용어 단일 출처 | 미정 |
| `09_api_contract/` | 소비하는 Backend-Core API 계약 | 초안 |
| `10_data_model/` | 화면 상태·뷰모델 | 미정 |
| `11_changelog/` | 변경 이력 | 초안 |
| `12_known_issues/` | 함정·안티패턴 | 미정 |
| `13_deploy_runbook/` | 배포 절차 | 미정 |

> 불일치 발견 시: 실제 코드를 따르고 불일치를 보고한다. 문서를 임의로 고치지 않는다.
